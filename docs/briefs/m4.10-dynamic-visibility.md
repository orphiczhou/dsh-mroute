# M4.10 任务书：让「动态层」真的看得见（0.8.1-m4.9.1）

> 本文是唯一正源。执行者先通读，再动手；偏离必须先回报裁决。

## 1. 背景与用户原话

M4.9（0.8.0-m4.9）已把动态沉底/窗口告警写回配置并渲染到面板。用户实际打开面板后说：

> 动态层（最近一次查询） · Dynamic layer (last query)
> 面板无法直连宿主，这里显示最近一次 model_route_query 写回的动态快照：沉底/提示渠道与原因。快照只读，保存不会修改它。
> **暂无动态数据：在会话里执行一次 model_route_query 后回到本页。**
> **还是没有显示最后一次动态数据。**

已核实的两个真实缺陷（不是用户操作问题）：

1. **空态吞掉了时间戳**：`client.js` 的 `DynamicCard` 在 `rows.length === 0` 时只渲染 `text.dynamicEmpty`，**即使 `snapshot.as_of` 有值**也不显示——而正常情况下（所有渠道都在安全线内）`rows` 就是空数组。于是「刚查过、全部正常」与「从没查过」在界面上完全一样。
2. **快照只存非 ok 行**：`lib/dynamic-state.js` 的 `buildDynamicSnapshot` 当前过滤掉 ok 渠道，导致面板无法展示「各渠道当前动态读数（窗口百分比/余额）」——用户想看的恰恰是这个。

## 2. 交付物（按序）

### 2.1 host：快照改为「全渠道」

`plugin-mroute/lib/dynamic-state.js` 的 `buildDynamicSnapshot(routes, asOf)`：

- **保留全部 routes**（顺序 = routes 顺序，即当前排序），不再过滤 ok；每行仍含：`id`、`state`（`'ok'|'hint'|'tight'|'unknown'`，与 `dynamicStateOf` 的返回保持一致）、`reason`（ok 行为空串）、`windows`（紧凑串，无窗口时 `''`）、`worst_used_pct`（无窗口时 `-1`）、`low_balance`（bool）、`display`（金额型展示串，无则 `''`）。
- `state` 若原先只允许 `tight|hint` 语义，请在 schema 注释与本函数头注里写清四值。
- `snapshotRowsEqual` 语义不变（逐行逐字段比）。
- 写回节流策略保持「rows 变化 或 as_of 超过 30 秒」，不要改成每次都写。

### 2.2 client：DynamicCard 重写渲染分支

`plugin-mroute/client.js` 的 `DynamicCard`：

- `as_of` 存在时**永远显示摘要行**：`快照时间 · snapshot time <as_of> · 沉底 N · 提示 M · 正常 K`（K = state==='ok' 行数）。
- 行渲染：`tight` → `⚠`；`hint` → `·`；`ok` → `✓`；`unknown` → `?`。每行尾部带读数：优先 `windows`，否则 `display`；都为空则不带。
- `as_of` 为空（即从没查过）才显示空态提示，文案改为「尚未收到任何查询快照：在会话里执行一次 model_route_query 后回到本页。」
- i18n：`zh`/`en` 各补 `dynamicOk`（`正常`/`ok`）、`dynamicNormalCount`（`正常`/`normal`）等所需键；所有新标签走 `bi()` 双语。**不要**引入新的 CSS 主题色 hack，沿用现有 `mroute-dynamic-*` 类。
- 面板保存的 ops **继续不得包含 `dynamic_snapshot`**（红线段断言要保留）。

### 2.3 自检

- `selfcheck/dynamic.test.mjs`：`buildDynamicSnapshot` 用例改为「全渠道、含 ok 行」；保留 §9.1 的扁平形状回归（含源码级禁止嵌套键读法）。
- `selfcheck/client.test.mjs`：新增/更新 DynamicCard 三分支渲染断言——①as_of 空 → 空态文案；②as_of 有值 + 全 ok → 摘要 + `✓` 行；③含 tight 行 → `⚠` + 原因。

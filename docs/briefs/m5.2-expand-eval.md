### 2.1 新题集 `plugin-mroute/lib/eval/suite-formal.mjs`（升级到 formal/2）

- `SUITE_VERSION = 'formal/2'`。
- 题量：**coding 13 / tools 13 / long_context 13 / orchestration 13 = 52 道判分题**；`world_knowledge` 哨兵 **2** 道（不计档）；`vision` **1** 道恒 `null`。合计 55 题 → 每模型 **54 次调用**。

- 新增题必须**可确定性判分**（字符串/正则/JSON 结构断言，禁 LLM judge），且必须写 `fixture_pass` / `fixture_fail`（对象形态 `{text, toolCalls?}`，与 formal/1 一致），保证 `sentinelCheck` 对 52+2 题全部双向自证 PASS。

### 2.2 `plugin-mroute/lib/tool-eval-run.mjs`

- 入参新增 **`max_tokens`**（可选，整数）：给所有可执行题覆盖 `maxTokens`，`validateArgs` 里 clamp 到 `[1, 200000]`，**校验先于任何 IO**；不传则用题面值。dry_run 的「预算」行要打印实际生效的 maxTokens 分布。
- `DAILY_CALL_BUDGET` 常量 **200 → 300**；description/文案同步（`model_eval_run` 的 tool description 与 `render()` 里的成本闸说明）。

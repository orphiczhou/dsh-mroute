## 3. 执行顺序（必须先做 §3.1 的探针并回报，再写实现）

### 3.1 schemastery 探针（阻塞项）

Day-1 已实测：`z.record` **不存在**、`z.dict` 存在；数组元素内禁 `.volatile()`（调用期抛 fixed-path 错），对象根 `.volatile()` 合法。

本任务要在 Config 顶层加「两层平铺的字符串映射」`model_aliases: { <channelId>: { <modelId>: <canonical> } }`（不固定键名）。**先用临时脚本实测三种写法**，取 roundtrip（`Config({...}).toJSON()` 再 `Config(...)`）byte-identical 且 `.volatile()` 合法的那个：

1. `z.dict(z.dict(z.string()))`；
2. `z.object({}).dict?` / 其它等效写法；
3. 若都不行：退化为 `z.array(z.object({channel, model, canonical}))`（**改形，需先回报 lead 裁决，不要擅自实施**）。

把探针输出（三种写法的结果）写进 `docs/05-m3-devlog.md` 的 §14.1，然后继续。

## 4. 红线（违反即打回）

1. **advisory-only**：别名只影响归并展示与档位解析；不改 `routes[]` 顺序、不剔除、不阻断。
